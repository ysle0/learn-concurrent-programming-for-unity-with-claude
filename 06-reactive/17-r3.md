# 17. R3

## 개요

**R3**는 UniRx/UniTask 개발자 neuecc가 만든 **차세대 Reactive Extensions** 라이브러리입니다. .NET 현대 기능(Source Generator, async/await 통합)을 활용하여 UniRx보다 더 높은 성능과 더 나은 개발 경험을 제공합니다.

## R3 vs UniRx 비교

### 주요 차이점

| 항목 | UniRx | R3 |
|------|-------|-----|
| **네임스페이스** | UniRx | R3 |
| **기본 타입** | IObservable<T> | Observable<T> (struct) |
| **Subject** | Subject<T> | ReactiveProperty<T>가 기본 |
| **완료 처리** | OnCompleted | OnCompleted + Result<T> |
| **Source Generator** | ❌ | ✅ (ObservableProperty) |
| **async/await** | ToObservable | 네이티브 통합 |
| **성능** | 좋음 | 더 좋음 (Zero-allocation) |
| **에러 핸들링** | OnError 전파 | Try/Catch 스타일 권장 |

### 핵심 설계 변화

```csharp
// UniRx: IObservable<T> 인터페이스 기반
IObservable<int> uniRxStream = Observable.Return(1);

// R3: Observable<T> 구조체 기반 (더 적은 할당)
Observable<int> r3Stream = Observable.Return(1);
```

## 기본 사용법

### Observable 생성

```csharp
using R3;
using UnityEngine;

public class R3Basics : MonoBehaviour
{
    void Start()
    {
        // Return: 단일 값
        Observable.Return(42)
            .Subscribe(x => Debug.Log($"Value: {x}"));

        // Range: 범위
        Observable.Range(1, 5)
            .Subscribe(x => Debug.Log($"Range: {x}"));

        // Timer: 일정 시간 후 발생
        Observable.Timer(TimeSpan.FromSeconds(2))
            .Subscribe(_ => Debug.Log("2 seconds passed"));

        // Interval: 주기적 발생
        Observable.Interval(TimeSpan.FromSeconds(1))
            .Take(5)
            .Subscribe(x => Debug.Log($"Interval: {x}"));

        // Create: 커스텀 Observable
        Observable.Create<int>(observer =>
        {
            observer.OnNext(1);
            observer.OnNext(2);
            observer.OnCompleted();
            return Disposable.Empty;
        })
        .Subscribe(x => Debug.Log($"Created: {x}"));
    }
}
```

public class R3Retry : MonoBehaviour
{
    void Start()
    {
        int attempt = 0;

        Observable.Create<string>(observer =>
        {
            attempt++;
            Debug.Log($"Attempt {attempt}");

            if (attempt < 3)
            {
                observer.OnError(new Exception("Failed"));
            }
            else
            {
                observer.OnNext("Success!");
                observer.OnCompleted();
            }
            return Disposable.Empty;
        })
        .Retry(3)
        .Subscribe(
            x => Debug.Log($"Result: {x}"),
            ex => Debug.LogError($"Failed after retries: {ex.Message}"))
        .AddTo(this);
    }
}

## UniRx에서 R3로 마이그레이션

### 네임스페이스 변경

```csharp
// UniRx
using UniRx;

// R3
using R3;
using R3.Triggers; // Unity 트리거용
```

### 주요 API 변경

```csharp
// === Subject ===
// UniRx
Subject<int> uniRxSubject = new Subject<int>();
BehaviorSubject<int> behaviorSubject = new BehaviorSubject<int>(0);

// R3
Subject<int> r3Subject = new Subject<int>();
ReactiveProperty<int> reactiveProperty = new ReactiveProperty<int>(0);

// === Buffer -> Chunk ===
// UniRx
observable.Buffer(3);

// R3
observable.Chunk(3);

// === AddTo ===
// 동일하게 사용 가능 (R3.Unity 필요)

// === ToObservable (Coroutine) ===
// UniRx
Observable.FromCoroutine<int>(MyCoroutine);

// R3: UniTask 권장
Observable.FromUniTask(MyUniTask);

// === OnErrorRetry ===
// UniRx
observable.OnErrorRetry(ex => { }, retryCount: 3);

// R3
observable.Retry(3);
```

### ReactiveProperty 변경

```csharp
// UniRx
public ReactiveProperty<int> Health = new ReactiveProperty<int>(100);
Health.Subscribe(hp => { });

// R3 (거의 동일)
public ReactiveProperty<int> Health { get; } = new ReactiveProperty<int>(100);
Health.Subscribe(hp => { });

// R3에서 달라진 점: Value 대신 CurrentValue (동기 접근)
int current = Health.CurrentValue;
```

### 마이그레이션 체크리스트

| UniRx | R3 | 비고 |
|-------|-----|------|
| `Buffer` | `Chunk` | 이름 변경 |
| `BehaviorSubject` | `ReactiveProperty` | 권장 변경 |
| `ObserveOnMainThread` | `ObserveOn(UnityFrameProvider.Update)` | 변경 |
| `UpdateAsObservable()` | `Observable.EveryUpdate()` | 변경 |
| `OnErrorRetry` | `Retry` + 커스텀 | 단순화 |

### 패턴 1: 상태 머신

```csharp
public class R3StateMachine : MonoBehaviour
{
    public enum GameState { Menu, Playing, Paused, GameOver }

    public ReactiveProperty<GameState> State { get; } = new ReactiveProperty<GameState>(GameState.Menu);

    void Start()
    {
        // 상태 전환 로깅
        State.Pairwise() // 이전 값과 현재 값 쌍
            .Subscribe(pair => Debug.Log($"State: {pair.Previous} -> {pair.Current}"))
            .AddTo(this);

        // 특정 상태 진입 시
        State.Where(s => s == GameState.Playing)
            .Subscribe(_ => OnEnterPlaying())
            .AddTo(this);

        // 특정 상태 종료 시
        State.Pairwise()
            .Where(pair => pair.Previous == GameState.Playing)
            .Subscribe(_ => OnExitPlaying())
            .AddTo(this);
    }

    void OnEnterPlaying() => Debug.Log("Game Started!");
    void OnExitPlaying() => Debug.Log("Game Stopped!");
}
```

### 패턴 3: 쿨다운 시스템

```csharp
public class R3Cooldown : MonoBehaviour
{
    [SerializeField] private Button _skillButton;
    [SerializeField] private Image _cooldownImage;

    public ReactiveProperty<bool> CanUseSkill { get; } = new ReactiveProperty<bool>(true);
    private float _cooldownDuration = 3f;

    void Start()
    {
        // 버튼 활성화 바인딩
        CanUseSkill.Subscribe(canUse =>
        {
            _skillButton.interactable = canUse;
        }).AddTo(this);

        // 클릭 시 스킬 사용
        _skillButton.OnClickAsObservable()
            .Where(_ => CanUseSkill.CurrentValue)
            .Subscribe(_ => UseSkill())
            .AddTo(this);
    }

    void UseSkill()
    {
        Debug.Log("Skill Used!");
        CanUseSkill.Value = false;

        // 쿨다운 시작
        Observable.EveryUpdate()
            .Select(_ => 1f - (Time.time % _cooldownDuration) / _cooldownDuration)
            .TakeUntil(Observable.Timer(TimeSpan.FromSeconds(_cooldownDuration)))
            .Subscribe(
                fill => _cooldownImage.fillAmount = fill,
                () =>
                {
                    _cooldownImage.fillAmount = 0;
                    CanUseSkill.Value = true;
                })
            .AddTo(this);
    }
}
```

{
    void Start()
    {
        // ✅ 좋음: 구조체 기반 Observable
        Observable.EveryUpdate()
            .Where(_ => Input.anyKeyDown)
            .Subscribe(_ => { })
            .AddTo(this);

        // ✅ 좋음: ForEachAsync로 allocation 감소
        StartForEachAsync();
    }

    async void StartForEachAsync()
    {
        await Observable.Interval(TimeSpan.FromSeconds(1))
            .Take(100)
            .ForEachAsync(x =>
            {
                // 처리
            }, destroyCancellationToken);
    }
}

## 정리

### R3 요약

| 항목 | 내용 |
|------|------|
| **핵심** | 차세대 Reactive Extensions |
| **개발자** | neuecc (UniRx 동일 개발자) |
| **특징** | Source Generator, Zero-allocation, async 통합 |
| **Unity 지원** | R3.Unity 패키지 |

### UniRx vs R3 선택 기준

| 상황 | 권장 |
|------|------|
| 기존 UniRx 프로젝트 | UniRx 유지 또는 점진적 마이그레이션 |
| 새 프로젝트 | R3 권장 |
| .NET 6+ 타겟 | R3 강력 권장 |
| 레거시 Unity 버전 | UniRx |
